# Настройки вашего проекта

Это шаблон с пустыми реквизитами. Заполните свои значения в приватном `.env` на сервере. Не записывайте пароли, токены или фразы восстановления в `.env.example` и не загружайте заполненный `.env` на GitHub.

## Основной шаблон — `.env.example`

Скопируйте его в `.env`. Для начала заполните:

| Что настроить | Поля |
| --- | --- |
| Название и адрес сайта | `APP_NAME`, `APP_URL` |
| Ключ приложения | `APP_KEY` — генерируется командой `php artisan key:generate` после установки зависимостей |
| Ваш администратор | `ADMIN_NAME`, `ADMIN_EMAIL`, `ADMIN_PASSWORD` |
| База данных | `DB_HOST`, `DB_PORT`, `DB_DATABASE`, `DB_USERNAME`, `DB_PASSWORD` |
| Redis | `REDIS_HOST`, `REDIS_PORT`, при необходимости `REDIS_USERNAME`, `REDIS_PASSWORD` |
| Источник данных TRON | `TRONGRID_NETWORK`, `TRONGRID_BASE_URL`, `TRONGRID_API_KEY`, `TRONGRID_USDT_CONTRACT` |
| Ссылки на транзакции | `TRONSCAN_BASE_URL` — необязательно, без него ссылка не отображается |
| Telegram | `TELEGRAM_BOT_NAME`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_WEBHOOK_URL`, `TELEGRAM_WEBHOOK_SECRET` |
| Почта | `MAIL_HOST`, `MAIL_PORT`, `MAIL_USERNAME`, `MAIL_PASSWORD`, `MAIL_FROM_ADDRESS`, нужный `MAIL_MAILER` |
| Геолокация | `IPGEOLOCATION_BASE_URL`, `IPGEOLOCATION_API_KEY` — необязательно |
| Хранилище файлов | Блок `AWS_*` — только если используете внешнее хранилище |

Сетевые порты и названия драйверов — стандартные параметры, их можно изменить. Адреса серверов, пользователи, пароли и ключи оставлены пустыми. `APP_DEBUG=false` установлен для публичной среды.

## Администратор

После настройки соединений и установки зависимостей выполните `php artisan app:install`.

Команда требует ваши `ADMIN_*` значения, включая пароль от 12 символов. Она применяет миграции без сброса существующей базы и создаёт нового администратора. Существующий аккаунт с тем же email не изменяет. Пароль и API-ключи в терминал не выводятся.

После создания администратора удалите `ADMIN_PASSWORD` из `.env` и обновите кеш конфигурации. Команда `db:seed` создаёт только роли: демонстрационные аккаунты и ключи больше не добавляются.

Шаблон не меняет пользователей или пароли в уже существующей внешней базе данных. Если такая база уже используется, её настройки и аккаунты нужно проверить отдельно.

## Адреса кошельков и сеть

Адреса для приёма платежей добавляются вами в разделе «Адреса» после входа. Предустановленных адресов получателей нет.

`TRONGRID_USDT_CONTRACT` — адрес контракта токена выбранной сети, а не ваш кошелёк. Заполните его проверенным значением для нужной сети. Основные поля `TRONGRID_BASE_URL` и `TRONGRID_USDT_CONTRACT` имеют приоритет над резервными полями `TRONGRID_TESTNET_*`; заполняйте основные поля явно. При смене сети проверьте одновременно endpoint и контракт. Без этих настроек блокчейн-запросы завершаются понятной ошибкой конфигурации.

В шаблоне выбрана тестовая сеть `nile`. Рабочие платежи не включены автоматически.

## API и уведомления

Ключ API и отдельный ключ callback генерируются для вашего аккаунта через раздел API в кабинете. Готовых значений в исходниках нет. Поле `PUBLIC_API_KEY` оставлено для совместимости исходной конфигурации; текущая авторизация маршрутов `/api/v1` использует ключи аккаунтов из базы данных.

URL получения callback и ссылка возврата задаются вами для своих магазинов и инвойсов. Документация использует шаблоны `YOUR_*` и зарезервированные домены `example.com` / `example.invalid`; это не действующие реквизиты.

Настройки Telegram относятся к вашему боту: username без `@`, токен и URL вашего обработчика `/telegram/webhook`. Пустой блок не выполняет настройку webhook сам по себе.

## Дополнительный тестовый отправитель

`wallet-signer/.env.example` — отдельный шаблон для вспомогательных тестовых скриптов. Основной приём оплаты на существующие адреса не требует фразы восстановления или приватного ключа.

Для тестового отправителя задайте `SANDBOX_WALLET_ID` в основном `.env`, а в `wallet-signer/.env` замените `YOUR_WALLET_ID` на этот идентификатор в верхнем регистре. Поля seed-фразы, адресов, API и сервера пустые. Интеграция отправителя ограничена Nile. Скрипты сами не запускаются.
