# Crypto USDT Pay

Шаблон сервиса приёма USDT в сети TRON: кабинет, магазины, клиенты, инвойсы, платёжная форма с QR-кодом и API.

Персональные реквизиты не заданы. Заполните собственные настройки по инструкции [docs/CONFIGURATION.md](docs/CONFIGURATION.md).

- Основной шаблон: [.env.example](.env.example).
- Дополнительный тестовый отправитель: [wallet-signer/.env.example](wallet-signer/.env.example).
- Документация API: [docs/API.md](docs/API.md).

Приложению нужны PHP 8.3+, Composer, MySQL, Redis и работающие фоновые очереди. Интерфейс собирается Node.js. Развёртывание и проверка платёжного цикла выполняются отдельно после заполнения настроек.
